# Contributing to Aether Weather 🌤️

First off, thank you for considering contributing to Aether Weather! It's people like you that make open source such a great community to learn, inspire, and create.

## How to Contribute

1. **Fork the Repository**
   Click the "Fork" button at the top right of this repository's page to create your own copy.

2. **Clone your Fork**
   ```bash
   git clone https://github.com/YOUR_USERNAME/Weather-Layout.git
   cd Weather-Layout
   ```

3. **Create a Branch**
   Create a new branch for your feature or bug fix:
   ```bash
   git checkout -b feature/your-feature-name
   ```

4. **Make your Changes**
   Make your changes to the code. Since this is a Vanilla HTML/CSS/JS project, you don't need any complex build tools. Just open `index.html` in your browser to test your changes locally.

5. **Commit your Changes**
   Write a clear, concise commit message:
   ```bash
   git add .
   git commit -m "feat: add some amazing feature"
   ```

6. **Push to your Fork**
   ```bash
   git push origin feature/your-feature-name
   ```

7. **Open a Pull Request**
   Go to the original repository and click "Compare & pull request". Provide a clear description of your changes and wait for a review!

## Hosting Your Fork

If you want to host your version of the app to show off your changes or test them in a live environment, you can easily do so for free since this is a static web application:

- **GitHub Pages:** Go to your fork's Settings > Pages > Source (Deploy from a branch) > select `main` (or your branch) > Save.
- **Vercel / Netlify:** Sign in to [Vercel](https://vercel.com) or [Netlify](https://netlify.com), create a new project, connect your GitHub account, and select your fork repository. It will deploy automatically without any configuration!
